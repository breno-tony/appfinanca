# Meu Financeiro — Supabase

Versão do MVP com:
- login simples por e-mail e senha;
- sessão persistente;
- dados sincronizados no Supabase;
- RLS por usuário;
- cópia local de apoio;
- entradas, saídas, vendas, comissão, salário e planejamento;
- backup JSON.

Comece pelo arquivo `SUPABASE_SETUP.md`.
